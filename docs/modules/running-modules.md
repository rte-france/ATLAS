# Run a Module

A module takes an `AtlasDataset` and a parameters file as input, runs its computation, and returns an updated `AtlasDataset` with all changes applied.

---

## Python

All modules are run through `ModuleRun`:

```python
from atlas import AtlasDataset
from atlas.modules.module_run import ModuleRun
from atlas.modules.day_ahead_orders import DayAheadOrdersModule

dataset = AtlasDataset.from_directory("./data/input/")

result = ModuleRun(
    module=DayAheadOrdersModule(),
    dataset=dataset,
    parameters="parameters.yml",
).run()
```

`ModuleRun.run()` returns an `AtlasDataset` with all changes applied.

Available modules:

| Class | Import |
|---|---|
| `DayAheadOrdersModule` | `atlas.modules.day_ahead_orders` |
| `MarketClearingModule` | `atlas.modules.market_clearing` |
| `PortfolioOptimisationModule` | `atlas.modules.portfolio_optimisation` |
| `IntradayPriceForecastModule` | `atlas.modules.intraday_price_forecast` |

---

## CLI

```bash
atlas run parameters.yml \
  --module DayAheadOrders \
  --dataset ./data/input/
```

| Option | Short | Required | Description |
|---|---|---|---|
| `config_path` | — | Yes | Path to the parameters YAML file |
| `--module` | `-m` | Yes | Module name (`DayAheadOrders`, `MarketClearing`, `PortfolioOptimisation`, `IntradayPriceForecast`) |
| `--dataset` | `-d` | Yes | Path to the input dataset directory |

## Loading Data

```python
# Lazy loading — files are read on first access (recommended for large datasets)
dataset = AtlasDataset.from_directory("./data/input/")

# Eager loading — all data loaded immediately into memory
dataset = AtlasDataset.from_directory("./data/input/", lazy=False)

# From existing objects
dataset = AtlasDataset(
    control_block=[cb],
    market_area=[area],
    node=[node],
    portfolio=[portfolio],
    thermal=[unit1, unit2],
    hydro=[plant1],
)
```

---

## Providing Parameters

**YAML file** (recommended):
```python
ModuleRun(module, dataset, parameters="parameters.yml").run()
```

**Dictionary**:
```python
ModuleRun(module, dataset, parameters={
    "temporal": {
        "start_date": "2024-01-01 00:00:00",
        "end_date": "2024-01-02 00:00:00",
        "execution_date": "2023-12-31 12:00:00",
        "timestep": "PT1H",
    },
}).run()
```

**JSON file**:
```python
ModuleRun(module, dataset, parameters="parameters.json").run()
```

See [Common Parameters](common-parameters.md) for the full parameter reference.

## Accessing Results

`ModuleRun.run()` returns the updated `AtlasDataset`. The objects it contains depend on the module:

```python
# Orders generated by Day-Ahead Orders
result = ModuleRun(module=DayAheadOrdersModule(), dataset=dataset, parameters="dao.yml").run()

for order in result.order.all():
    print(f"{order.name}: {order.price} €/MWh, qmax={order.qmax} MW")

# Market prices after Market Clearing
result = ModuleRun(module=MarketClearingModule(), dataset=result, parameters="mc.yml").run()

for area in result.market_area.all():
    print(f"{area.name}: {area.da_price}")

# Power output per equipment after Portfolio Optimisation
result = ModuleRun(module=PortfolioOptimisationModule(), dataset=result, parameters="po.yml").run()

execution_date = ...
for thermal in result.thermal.all():
    power = thermal.power.get_forecast(execution_date, start_date, end_date)
    print(f"{thermal.name}: {power}")

# Total portfolio power
for portfolio in result.portfolio.all():
    total_power = portfolio.power.get_forecast(execution_date, start_date, end_date)
    print(f"{portfolio.name}: {total_power}")
```

See each module's [Results](day-ahead-orders/user-guide/results.md) page for the full output reference.

## Exporting Results

```python
# Export updated dataset to disk
result.to_directory("./data/output/")

# Export as pickle (faster for intermediate results)
result.to_pickle("./snapshots/after_dao.pkl")
```

## Performance

### Lazy Loading

For large datasets, use lazy loading to defer file reads until data is actually accessed:

```python
dataset = AtlasDataset.from_directory("./data/input/", lazy=True)
```

### Multiprocessing

Modules that support parallel execution (Portfolio Optimisation, Day-Ahead Orders) accept a `multiprocessing` block in parameters:

```yaml
multiprocessing:
  enable: true
  max_workers: 4
```

### Solver

For optimisation modules, tune solver settings to balance speed and precision:

```yaml
solver:
  solver_name: "SCIP"
  timeout: "PT5M"
  duality_gap: 0.01
  use_presolve: true
```
