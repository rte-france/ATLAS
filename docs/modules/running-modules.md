# Run a Module

A module takes a dataset and a parameters file as input, runs its computation, and returns an updated `AtlasDataset` with all changes applied.

---

## Python

All modules are run through `ModuleRun`:

```python
from atlas import ModuleRun, DayAheadOrdersModule

result = ModuleRun(
    module=DayAheadOrdersModule,
    dataset="./data/input/",
    parameters="parameters.yml",
).run()
```

`ModuleRun.run()` returns an `AtlasDataset` with all changes applied.

`module` accepts the class or its registry name as a string:

```python
# String name — useful for dynamic dispatch
ModuleRun(module="DayAheadOrders", dataset="./data/input/", parameters="parameters.yml").run()
```

Available modules:

| String name | Class | Import |
|---|---|---|
| `DayAheadOrders` | `DayAheadOrdersModule` |
| `MarketClearing` | `MarketClearingModule` |
| `PortfolioOptimisation` | `PortfolioOptimisationModule` |
| `IntradayPriceForecast` | `IntradayPriceForecastModule` |

---

## CLI

```bash
atlas module run DayAheadOrders \
  -p parameters.yml \
  -d ./data/input/
```

| Argument / Option | Short | Required | Description |
|---|---|---|---|
| `MODULE_NAME` | — | Yes | Module name. Run `atlas module list` to see all available modules. |
| `--parameters` | `-p` | Yes | Path to the parameters YAML file |
| `--dataset` | `-d` | Yes | Path to the input dataset directory |

---

## Dataset argument

`dataset` accepts a path or an `AtlasDataset` object:

```python
# Path — loaded automatically (recommended)
ModuleRun(module=DayAheadOrdersModule, dataset="./data/input/", parameters="parameters.yml").run()

# Pre-loaded AtlasDataset — when constructing data in code or chaining modules
from atlas import AtlasDataset

dataset = AtlasDataset(
    control_block=[cb],
    market_area=[area],
    node=[node],
    portfolio=[portfolio],
    thermal=[unit1, unit2],
    hydro=[plant1],
)
ModuleRun(module=DayAheadOrdersModule, dataset=dataset, parameters="parameters.yml").run()
```

## Providing Parameters

**YAML file** (recommended):
```python
ModuleRun(module=DayAheadOrdersModule, dataset="./data/input/", parameters="parameters.yml").run()
```

**Dictionary**:
```python
ModuleRun(module=DayAheadOrdersModule, dataset="./data/input/", parameters={
    "temporal": {
        "start_date": "2024-01-01 00:00:00",
        "end_date": "2024-01-02 00:00:00",
        "execution_date": "2023-12-31 12:00:00",
        "timestep": "PT1H",
    },
}).run()
```

**JSON file**:
```python
ModuleRun(module=DayAheadOrdersModule, dataset="./data/input/", parameters="parameters.json").run()
```

See [Common Parameters](common-parameters.md) for the full parameter reference.

## Accessing Results

`ModuleRun.run()` returns the updated `AtlasDataset`. The objects it contains depend on the module:

```python
# Orders generated by Day-Ahead Orders
result = ModuleRun(module=DayAheadOrdersModule, dataset="./data/input/", parameters="dao.yml").run()

for order in result.order.all():
    print(f"{order.name}: {order.price} €/MWh, qmax={order.qmax} MW")

# Market prices after Market Clearing — pass the previous result as dataset
result = ModuleRun(module=MarketClearingModule, dataset=result, parameters="mc.yml").run()

for area in result.market_area.all():
    print(f"{area.name}: {area.da_price}")

# Power output per equipment after Portfolio Optimisation
result = ModuleRun(module=PortfolioOptimisationModule, dataset=result, parameters="po.yml").run()

execution_date = ...
for thermal in result.thermal.all():
    power = thermal.power.get_forecast(execution_date, start_date, end_date)
    print(f"{thermal.name}: {power}")

# Total portfolio power
for portfolio in result.portfolio.all():
    total_power = portfolio.power.get_forecast(execution_date, start_date, end_date)
    print(f"{portfolio.name}: {total_power}")
```

See each module's [Results](day-ahead-orders/user-guide/results.md) page for the full output reference.

## Performance

### Lazy Loading

When passing a path to `ModuleRun`, data is loaded lazily by default — files are read on first access. To force eager loading, pre-load the dataset explicitly:

```python
from atlas import AtlasDataset

dataset = AtlasDataset.from_directory("./data/input/", lazy=False)
ModuleRun(module=DayAheadOrdersModule, dataset=dataset, parameters="parameters.yml").run()
```

### Multiprocessing

Modules that support parallel execution (Portfolio Optimisation, Day-Ahead Orders) accept a `multiprocessing` block in parameters:

```yaml
multiprocessing:
  enable: true
  max_workers: 4
```

### Solver

For optimisation modules, tune solver settings to balance speed and precision:

```yaml
solver:
  solver_name: "SCIP"
  timeout: "PT5M"
  duality_gap: 0.01
  use_presolve: true
```
